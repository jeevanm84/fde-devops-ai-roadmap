# Zero-to-advanced DevOps ladder (with AI layer)

Rate yourself honestly. Skip levels you already own, but do the "prove it" step so any gap is visible.

| Level | Skills | Prove it |
|---|---|---|
| 0 Foundations | Linux, networking (DNS, TLS, HTTP, VPC), Git, Python/Bash, YAML/JSON | Script that parses logs and calls an API |
| 1 Containers and CI | Docker, Compose, registries, GitHub Actions/Jenkins, artifact versioning | Pipeline that builds, tests, scans and pushes an image |
| 2 Orchestration and IaC | Kubernetes (Deployments, Services, Ingress, StatefulSets, probes), Helm, Terraform, state management | Cluster plus app deployed from code, torn down cleanly |
| 3 Reliability | SLIs/SLOs, Prometheus/Grafana, alerting, incident response, postmortems, capacity and cost | Alert-to-runbook path with a real postmortem |
| 4 Platform and security | GitOps (Argo/Flux), policy as code, IAM least privilege, secrets management, multi-account governance | PR-driven change with policy gate and audit trail |
| 5 AI-enabled operations | LLM APIs, prompt design, RAG, agents, MCP, evals, guardrails, LLMOps, cost control | Capstone: AI ops copilot with approvals, evals and monitoring |
| 6 FDE | Discovery, scoping, rapid POCs, customer-system integration, demos, handoff and training | Customer-ready POC delivered in two weeks |

If you already run Kubernetes and AWS in production, you are likely at level 4. Your fastest gains are levels 5 and 6.
