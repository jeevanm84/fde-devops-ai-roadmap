# FDE skills

A Forward Deployed Engineer ships working solutions inside a customer's environment, then feeds lessons back to the product team. Technical depth is necessary; the rest is what differentiates.

## Skills to practice
1. **Discovery:** ask for the workflow, the pain, the data, the constraints, and who decides. Write a one-page problem statement.
2. **Scoping:** turn vague asks into a 2-week POC with a success metric and explicit non-goals.
3. **Integration:** SSO, private networking, data residency, existing ticketing and monitoring. Expect messy systems.
4. **Demo:** 5-minute story, rehearsed live path, fallback recording.
5. **Handoff:** runbook, architecture diagram, cost estimate, training session, support path.
6. **Communication:** status updates that state risk, decision needed, and next step.

## 2-week POC playbook
| Day | Focus |
|---|---|
| 1-2 | Discovery, success metric, data access, security review |
| 3-5 | Thin vertical slice working end to end with real data |
| 6-8 | Evals on real cases, guardrails, failure handling |
| 9-10 | Deploy to the customer environment, monitoring, cost limits |
| 11-12 | User testing, fixes, demo script |
| 13-14 | Demo, decision memo, handoff docs, backlog |

## Weekly scenario drill
Pick one: invoice triage, incident copilot, support-ticket routing, compliance Q&A, log summarization, cost anomaly explainer. Write: problem, users, data, architecture, risks, metric, 2-week plan.
